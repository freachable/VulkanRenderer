# Proposed Project Structure

> Proposal by P1, for discussion. Nothing outside P1's folders is moved until the team agrees.

## Directory tree

```
VulkanRenderer/
├── README.md              Overview, build & run, how to generate map data
├── CMakeLists.txt         (plus CMakePresets.json, vcpkg.json, ...)
├── cmake/
├── docs/                  Detailed documentation
│   ├── structure.md
│   └── map-data-format.md
├── assets/                All runtime resources
│   ├── textures/          (moved from the current root textures/)
│   ├── maps/
│   │   └── sample/        Map datasets (heightmap, albedo, buildings, foliage)
│   └── splats/            Landmark and foliage splat files
├── shaders/
│   ├── mesh/              terrain.slang, building.slang
│   └── splat/             Splat projection, sorting, billboard shaders
├── src/
│   ├── main.cpp
│   ├── Application.*
│   ├── platform/          Window, input
│   ├── graphics/          Vulkan framework
│   ├── camera/            Camera
│   ├── map/               Map loading, terrain and building meshes
│   └── splat/             Splat loading, projection, sorting, drawing
└── tools/                 Offline Python preprocessing scripts
```

## Ownership

| Folder | Owner |
|---|---|
| `src/platform/`, `src/graphics/`, `src/camera/`, `src/Application.*` | P4 |
| `src/map/`, `shaders/mesh/`, `assets/maps/`, `tools/` | P1 |
| `src/splat/`, `shaders/splat/` (compute: projection, culling, sort) | P2 |
| `src/splat/`, `shaders/splat/` (raster, compositing), `assets/splats/` | P3 |
| `README.md`, `docs/`, `CMakeLists.txt` | Shared |

## Rationale

- **One kind of content per folder.** `src/` holds only C++ code, `shaders/` only Slang, `assets/` only runtime data, `tools/` only offline scripts.
- **Fewer merge conflicts.** Each folder has mostly one owner, so PRs rarely touch the same files.
- **One place for resources.** `assets/` gives splat files, textures and future data (e.g. a skybox) a fixed location.
- **Data stays out of `src/`.** Large binary files would make the source tree harder to navigate and review.
